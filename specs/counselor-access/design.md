# 设计

继续使用现有 CloudRun 会话和 NoSQL 事务，不引入另一套前端身份平台。

- 新增仅服务端可读写的 `xg_counselor_accounts`、`xg_counselor_invites`；物理名称沿用正式/preview 前缀。账号按咨询师 ID 保存，手机号只存 SHA-256 绑定摘要；登录时从最小投影的咨询师目录定位唯一档案。失败计数、锁定时间和会话版本放在账号记录中。
- 初始改密、资料填写、正常工作台使用不同 audience。初始凭证不能读档案；资料填写凭证不能调用普通 REST 和四评接口。每次使用手机号会话都校验账号版本及当前手机号；每次使用分享会话都验证链接版本、撤销状态和到期时间。
- 分享令牌包含咨询师 ID 和 256 位随机秘密，只存摘要，链接秘密放在 URL fragment；打开后立即移除 fragment，并仅在页面内存保存受限会话。链接有效 7 天，会话最长 30 分钟。
- 管理员可重置手机号账号为初始密码，清除锁定并增加版本；不自动重置已设置的密码。
- 首页和工作台提供手机号/密码表单与首次改密步骤，保留旧短码入口。分享页面复用现有资料编辑面板，保存后保持在资料页，不跳转到来访者工作台。

界面目的：让管理员能够准确发放指定档案，让咨询师完成验证和补齐。沿用现有自然风格：主色 `#5C7A52`、背景 `#FAF9F6`、文字 `#3D3831`、边框 `#E8E4DC`、错误色 `#B54336`；字体沿用 PingFang SC / Microsoft YaHei。复用现有模态框、左对齐字段和按钮，不改造原站布局。表单反馈紧邻操作按钮，分享 URL 只在生成当次显示。

验证覆盖：角色/audience 隔离、初始改密、旧会话撤销、重复手机号、持久锁定、链接重发/撤销/过期、资料越权、图片私有化、管理员复制到咨询师填表的浏览器链路。
