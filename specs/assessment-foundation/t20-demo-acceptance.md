日期：2026-10-25。状态：本地演示包、验收样例及回归完成；未连接真实数据库、未部署、未发送真实通知、未调用真实模型。

## 使用方式与交付物

```bash
# 从项目根目录运行；无需任何密钥或云环境配置
npm run demo:assessment

# 完整后端回归，包含T20的HTTP权限验证
npm run test:cloudbase
```

- [演示摘要](../../outputs/t20/demo-summary.json)：2个咨询周期、21份有效提交、原始/展示信号、阶段档案、通知兜底和明确标记的模拟LLM结果。
- [验收报告](../../outputs/t20/acceptance-report.json)：R01–R14全部需求样例、N01–N10补充反例，共24个场景的实际断言结果。
- [合成数据生成器](../../scripts/fixtures/assessment-demo.cjs)：固定身份、时间与答案，使用当前业务模块生成结果。
- [可执行验收样例](../../scripts/fixtures/assessment-acceptance.cjs)：场景步骤及独立期望值，任何断言失败都使命令失败。
- [运行入口](../../scripts/verify-assessment-demo.cjs)：验收通过后输出两个JSON文件；不接受环境、数据库、地址或导入参数。
- [T20回归测试](../../cloudrun/xiaopingu-api/assessment/demo-acceptance.test.js)：24场景、主案例完整性、重复运行一致性和两组HTTP权限反例。

每次运行创建全新的进程内存储，不读取既有业务数据、环境变量或账号配置，也不接收外部数据库实例。导出标记 `synthetic=true`、`importable=false`，是复核材料，不是云端导入包。固定业务键和时间使重复运行的摘要一致；同时验证同一提交请求重放不增加事件或回执。没有修改下载目录的原始交付文件，也不执行原SQL。

测试使用本地受信任合成身份调用业务模块，不是开放真实演示登录。真实HTTP仍拒绝 `demo=true` 会话；来访身份入口、周期归属和私有集合访问限制保持原样。生成器位于 scripts/fixtures，未接入服务启动或部署镜像。
