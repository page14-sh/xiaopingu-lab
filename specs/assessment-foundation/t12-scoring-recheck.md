# T12｜固定量程计分、基线重测与历史复算

日期：2026-10-25。状态：本地实现与专项验收完成，未部署。

## 计分实现

将既有计算整理为显式版本引擎 `scoring-engines.js`，当前注册 `xg-core-t03-v1`。所有作答先通过T11校验，再按事件冻结的engine_id选择实现。未注册引擎返回503 `XG_RULE_ENGINE_UNAVAILABLE`，不回退到最新算法，不保存提交或分数。未来算法变更须注册新ID；本次整理保留原有计算结果。

| 分数 | 固定公式/范围 |
| --- | --- |
| M0/M1核心 | s1–s7之和，0–70；百分比固定除以70 |
| ORS对照 | round((s1+s2+s3)/3+s4+s5+s6)，0–40 |
| 附加分 | s7，0–10；不加入ORS |
| 选修稳定化 | s8+s9+s10，0–30；关闭为null，开启后全0为0 |
| M0补足/资源/解离 | b1–b3之和0–30；r1+r2为0–20；d1原值0/1/2；均不改变核心主分 |
| M2感受 | f1–f4之和，0–40 |
| M3对照 | 通常p1–p6之和，0–60；首节p6不适用，total/pct为null |
| M4结案 | e1–e6之和，0–60；补足为e3+e4+e5，0–30 |
| M4服务评价 | v1–v3之和，0–30；o1不计分 |
| M4随访 | u1–u6之和，0–60；补足为u2+u3+u4，0–30 |

百分比保留两位小数，原始总分保留整数。阈值判定应使用原始总分/精确比例，不能用展示百分比替代；实际预警与跨卡差异在T13/T14继续实现。基线、结案、随访仍分阶段展示，不新增跨阶段同量尺差值。

质量标记继续使用服务器实际耗时及冻结规则。客户端duration_ms只留档，不能改变质量结果。合法短时作答被接受并标记low；M0混合合法答案在60秒提交可以成功，65秒边界按现有规则验收。

## 首节重测

重测使用M1、session_no=1，并在开始、恢复填写和提交时核验：

1. 本周期存在原始M0，以其submitted_at计算间隔，不能改用开始时间。
2. 当前时间必须严格超过冻结规则的late_recheck_days（默认7天）；恰好7天仍不可重测。
3. 周期仍为active，且尚无第1节及之后的成功会谈卡记录（last_session_no仍为0）。
4. 同一位置只能有一次成功重测；失败、放弃及超时不占成功名额。

提交时再次核验可防止填写期间另一张首节卡成功后，迟到的重测再更新参照值。不符合条件返回409 `XG_RECHECK_NOT_DUE`；开始失败不创建事件、回执或审计。已有终态操作的原键重试仍遵循T10，不重复执行业务写入。

原始M0与重测分别保存为baseline.original和baseline.recheck；事务内更新重测、事件、名额、审计和回执，原始M0保持不变。重测失败时继续使用原始基线；有效重测后常规M1不再改变参照值。

当前“首节前”按已落库的成功卡片节次判断；本项目尚未提供独立的会谈开始时间事件。推卡和页面引导继续由后续任务接入。低层可信导入原语保留T04约定，公众请求只走带上述守卫的生命周期服务。

## 参照基线与趋势

仓库提供 `referenceBaseline`：优先选择该周期的成功首节重测，否则选择原始M0。0分是有效参照，不能用真值判断误回退。所选记录缺失、节次不符或主分不合法时明确报错，不猜测或补值。

`GET /v1/xg/trend?match_id=...` 继续只向获授权的咨询师和管理员开放，新增：

```json
{
  "reference_baseline": {
    "source": "late_recheck",
    "event_id": "历史事件ID",
    "session_no": 1,
    "total": 35
  }
}
```

示例省略其他允许字段；source只有original或late_recheck。baseline与recheck仍分别保留。points现在只含session_no>=2的成功M1，首节重测不再混入常规观察序列。参照选择、原始基线和趋势页共同受周期revision一致性检查保护，跨周期不继承参照值。

## 只读历史复算

新增管理员接口：

`GET /v1/xg/admin/event-score-replay?match_id=...&event_id=...`

仓库在一个只读事务中读取周期与事件，校验归属和冻结依据完整性，然后使用历史engine_id、冻结规则、原始答案及服务器duration_ms重新计算。不会读取最新题库来代替历史依据，不修改事件、档案、回执或规则版本。

返回字段：

- event_id、match_id、engine_id及basis_ref。
- stored/recomputed：允许的数值分数字段和质量标记。
- matches：是否一致；differences：不一致字段，如scores.total、quality_flag。

没有原始答案、完整题面、请求头或凭据回显；响应no-store。来访和咨询师不能调用该审计接口，跨周期event_id被拒绝，不开放POST写入或“自动修复”。若分数不同，保留原记录并返回差异，后续修复须单独审阅。

| 不可复算情况 | 处理 |
| --- | --- |
| 不是submitted | 409 XG_REPLAY_NOT_SUBMITTED |
| 历史未捕获basis | 409 XG_BASIS_REQUIRED，不构造历史版本 |
| basis哈希或归属异常 | 409依据错误或403归属拒绝 |
| 历史引擎不支持 | 503 XG_RULE_ENGINE_UNAVAILABLE |
| 缺少可信服务器耗时 | 409 XG_REPLAY_DURATION_MISSING，不用客户端耗时代替 |
| 原始答案不符合历史题面 | 409 XG_REPLAY_ANSWERS_INVALID |
| 存储分数含未知字段或非法数值 | 409 XG_REPLAY_SCORES_INVALID |
