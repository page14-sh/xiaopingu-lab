## 新增联调工具及保护

- [主运行器](../../scripts/t21-isolated-integration.cjs)：`--run`执行完整隔离链路；`--probe-conflicts`执行单集合冲突探针；`--cleanup <报告>`恢复清理。
- [资源适配器](../../scripts/integration/t21-cloud.cjs)：固定演示EnvId，临时CLI凭据只在内存，强制逻辑集合映射，未知集合拒绝；预检查不存在后记录创建意图。
- 集合与索引准备最多3路并行，所有同批操作settled后才进入错误处理/清理，避免后台未结束的创建遗漏。
- 清理只接受当前T21格式、固定环境、符合命名规则且位于白名单内的资源；错误环境、foreign集合及重复目标均拒绝。删除后读取确认不存在，清理失败不标记整体通过。
- 只持久化安全错误码，不保存SDK/CLI完整错误、服务商响应体、凭据或模型输入。

```bash
node scripts/t21-isolated-integration.cjs --run
node scripts/t21-isolated-integration.cjs --probe-conflicts
node scripts/t21-isolated-integration.cjs --cleanup outputs/t21/<本轮报告>.json
```

脚本使用`tcb secrets get`当前临时登录，目标环境必须可访问；不能把这个入口用作生产迁移或部署工具。旧T10脚本和原业务迁移脚本未被改成新的自动启动步骤。
