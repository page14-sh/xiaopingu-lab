## 角色矩阵

所有四评读取先执行 T05 的可信会话和账号有效性校验，再按明确的 match_id 验证周期归属。来访/咨询师不能因同一个来访还有其他咨询关系而获得跨周期权限；管理员也必须明确指定一个周期查询。

| 读取内容 | 来访 | 对口咨询师 | 管理员 |
|---|---|---|---|
| 作答历史 | 本周期本人卡片的 ID、卡片类型、节次/轮次、状态、创建/提交时间 | 本周期 M2/M3 的元数据、主分、百分比及题号白名单内的数值答案 | 指定周期全部卡片的元数据、指定分数与题号白名单内答案 |
| M3 咨询师卡片 | 不返回，直接指定该卡或其事件 ID 返回403 | 本周期可读 | 可读 |
| 原始答案 | 不返回 | 仅 M2 的 f1–f4、M3 的 p1–p6 数值 | 按卡片题号白名单；开放反馈 o1 只对管理员返回，最多2000字符 |
| 状态趋势 | 403 | 本周期可读 | 指定周期可读 |
| 基线/结案/随访阶段汇总 | 403 | 本周期指定汇总分可读，不含原始自由文本、风险标签等档案字段 | 同一汇总契约 |
| LLM 结果 | 403 | 本周期有效结果的白名单字段 | 同一白名单与输出过滤规则 |
| 系统内部字段 | 不返回 | 不返回 | 不因管理员身份自动全量返回 |

“系统内部字段”包括数据库 _id、提交名额、actor 身份、未来新增字段、原始模型响应、系统提示词、API Key 等。响应基于正向白名单构造；不采用“先返回整行，再删除几个敏感字段”的方式。

来访作答历史也不返回 quality_flag、任何分数字段（包括 supp_total / stability_total / dissoc_level）、原始答案或 AI 输出。卡片可见性先过滤再分页，不返回全量记录计数来暴露隐藏的 M3 记录。

## 已开放的读取接口

| 接口 | 参数与返回 |
|---|---|
| GET /v1/xg/events | 必填 match_id；可选 event_id / scale_code / session_no / follow_round / limit / offset；返回 `{events:[...]}` |
| GET /v1/xg/trend | 必填 match_id；可选 from_session / to_session / limit / offset；scale_code 如提供只能是 xg_m1_state；返回原始 baseline、独立 recheck 和状态 points |
| GET /v1/xg/person-compare | 必填 match_id；返回 baseline、recheck、end、follow_1m、follow_3m 的指定汇总字段，不计算跨阶段差值或生成同量尺连线 |
| GET /v1/xg/llm-results | 必填 match_id；可选 event_id / limit / offset；返回 `{results:[...]}`；结果来源集合由 T19 worker 后续写入 |

分页默认 limit=50，范围1–200；offset 为0–100000的整数。事件/趋势在完成权限过滤后分页，LLM 按存储结果文档分页后过滤无效内容，因此某页可能不足 limit 条；查询不返回隐藏记录总数。

查询参数不支持 user_id 范围查询、角色切换或任意投影。`select=*`、`role=admin`、重复 match_id、未知参数、非法轮次及非法分页值均返回400。不能仅凭 event_id 读取，必须同时提供周期；事件与周期不符返回403。

响应体所有分数字段仅接受有限数值，嵌套对象等异常类型不会作为分数透传；原始答案只返回允许的题号及类型。趋势与阶段汇总会再次裁剪底层快照，避免档案后来增加的自由文本或内部元数据被连带返回。

所有四评专用接口及 `/auth/visitor` 响应（包括失败响应）统一设置 `Cache-Control: no-store` 和 `Vary: Authorization`，避免身份相关响应被缓存复用。

## LLM 读取契约

新增私有集合 xg_llm_results，以 event_id 为文档 ID，必须带 match_id、visitor_id、counselor_id。读取过程同时验证：

1. 请求者可访问该周期。
2. 结果的冗余身份属于该周期，文档 ID 等于其 event_id。
3. 结果引用的事件属于该周期且已成功提交；session_no 取自事件，不相信结果上的冗余节次。

仅输出 event_id、session_no、四个固定 dim_scores、summary、suggest_actions、model、prompt_version、scored_at。四个维度为 ORS / 联盟 / 稳定度 / 目标进展，各值0–100。维度对象上的其他字段会丢弃。

摘要必须为非空且不超过60字符的字符串；建议最多2条、每条最多200字符。摘要或建议命中交付包禁用词，或维度/建议结构不合法时，该条结果不返回，即使请求者是管理员也一致处理。原始模型输出、提示词和内部凭据始终不返回。

本项只实现安全读取，不生成 LLM 结果，也不把词过滤当成完整的模型输出质量审查。结果生成、失败任务/人工复核状态写回由 T19 完成。

## 对旧接口和直接数据库访问的限制

- 新增 LLM 集合和此前全部四评集合均不在旧 `/rest/v1/*` 白名单中；所有角色经旧路径访问都返回404。
- T05 创建的 xg_managed 来源评估继续受旧接口保护；本项没有把四评分数回写到旧 pcoms_ratings。
- 旧演示 PCOMS/准入评估接口的历史契约不等于新四评接口契约；本项的角色白名单针对 `/v1/xg/*`。不把旧演示读写策略当作四评的权限保证。
- [集合声明](../../cloudrun/xiaopingu-api/assessment/collections.json)现有12个私有集合，统一要求客户端直接读写拒绝，并增加 LLM 的 match_id + _id 查询索引声明。
- 声明不等于已配置的云端规则。本次没有创建集合、索引或变更实际权限；启用前仍要在真实环境验证客户端拒绝、服务端可用及角色隔离，不能把本地测试当成云端权限验收。
