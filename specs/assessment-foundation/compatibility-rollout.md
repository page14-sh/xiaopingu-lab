# 旧版兼容与隔离预览

2026-10-25。此文件记录本轮用户确认和实现范围；不改变 T21/T22 历史报告中的测试对象与证据。

## 已确认的业务决定

| 项目 | 决定及执行边界 |
| --- | --- |
| 旧数据 | 包含真实数据。保留原集合与旧服务，不覆盖、不清空、不将旧分数转换为新七题基线。 |
| 进行中的咨询 | 没有。新流程建立新周期；旧记录保留历史，不补造周期。 |
| 旧入口和准入 | 保留。隔离预览增加受验证身份保护的 `/v1/xg/bridge/enter`，继续接受 `{asid}`；旧前端仍由旧服务提供。仅凭 ASID 换取身份令牌的旧行为不沿用，真实客户端身份对接仍待验收。 |
| 风险复查卡 | 保留原题及 0／5／10 选项；存在本周期未关闭的结果线 L3 才可填写，距上次复查至少两节。5 为安全 L2，10 为安全 L3 并停止本周期后续填卡；不计入核心七题总分。 |
| 恢复曲线 | 关闭，未加入预测曲线算法或展示。 |
| 动态关注点 | 人工维护；不启用自动动态题刷新。 |
| 通知和 LLM | 暂不开放真实通道。预览运行时强制关闭外部通知和模型调用；不安装定时器。站内记录不代表外部消息已发送。 |

## 兼容实现

- `items-compat-v1.json` / `rules-compat-v1.json` 新增独立版本，包含 8 张卡、43 道题；旧 7 卡版本仍可重放，已提交事件的题目、规则、分数快照不变。
- 风险复查使用独立周期状态；风险提交、停填与事件持久化在同一事务内完成。重复提交仍返回原收据，不能用更换请求号重复计入。
- 准入筛查的 `active` / `action` 拒绝新匹配，`safe` / `passive` 保留后续流程。只允许本人已验证身份创建的受管理初评进入桥接；不自动接管真实旧 ASID。
- 风险题仍受知情同意、角色、周期和版本约束；来访者接口不返回原始分数。紧急安全提醒不受普通提醒关闭影响。
- 真实通知必须显式配置 `XPG_EXTERNAL_NOTIFICATIONS_ENABLED=1`，LLM 必须显式配置 `XPG_LLM_ENABLED=1`。预览模式即便误配这两个值也不会调用真实服务。

## 隔离部署边界

目标为现有 CloudBase 演示环境中的**新增预览服务**，不替换 `xiaopingu-api`、`xiaopingu-xg-api` 或旧 `xg-api` 云函数。不是 OceanBase 数据库迁移。

`XPG_PREVIEW_MODE=1` 必须配合 `xg_preview_<4–12位小写字母数字>_` 集合前缀；缺失或非法前缀直接拒绝启动。全部 43 个四评集合及 5 个旧 API 依赖均映射到新前缀，事务同样映射，未声明集合直接拒绝访问。全部集合使用 ADMINONLY，不复制旧真实用户、咨询师或咨询记录。

预览只验证后端 API 与合成账号；不展示旧 PCOMS 页面冒充四评界面，不配置真实微信身份函数、真实收件人或模型，不向真实用户导流。新服务采用最小实例 0、最大实例 1，沿用 Trial 环境，不升级套餐。

初始与验收后的全局状态均为 `collection_paused=true`、`enable_reminder=false`、`enable_cst=false`、`emergency_stop=true`。合成联调需要开放采集时，在隔离命名空间内短暂调整并恢复；旧服务的开关不变。

## 验收与尚未完成的正式发布条件

本轮本地回归为 514 项通过（含 17 项新增兼容测试）。CloudRun 与真库运行结果单独记录，不以本地测试替代。T21 哈希已因运行时代码变化失配，原 T21 报告只证明旧提交；没有修改其哈希以伪造新版本通过。

本次决定关闭了业务范围上的主要歧义，但完整四评前端、真实微信身份与旧入口适配、正式同意文案、运营与恢复演练仍未验收。真实通知和 LLM 按用户决定延期，不是已验收。隔离 API 预览不等于正式产品可上线。
