# 手机号登录与资料填写链接

## 管理员操作

在「咨询师资料」找到本人，点击「填写链接」打开操作框：

- **生成新链接**：产生 7 天有效的资料链接；旧链接及其已换取的填写会话失效。
- **复制链接**：单独发给该咨询师。链接允许补充指定档案，不包含工作台或来访者权限。
- **撤销链接**：立即停止旧链接后续读取、保存。已显示在浏览器里的内容无法远程抹除。
- **重置手机号登录**：核实本人后，将该手机号登录恢复为手机号后 6 位，并强制再次改密；现有手机号登录会话失效。不会重置旧编辑码或短登录码。

手机号缺失时也可以发填写链接，先请本人补充联系方式。密码重置要求手机号有效且在全部咨询师档案中唯一。初始手机号密码可被推算，运营应私下发放并让本人尽快完成改密，不应将它作为长期密码。

## 咨询师操作

1. 打开管理员发来的完整链接，补充资料并点击「保存档案」。成功后可关闭页面；有效期内可以再次打开原链接继续填写。
2. 已审核、启用的咨询师，可在首页「咨询师登录」或工作台登录页使用档案内的中国大陆手机号。支持 `+86` 格式；首次密码为后 **6 位**。
3. 首次验证后先设置 10–128 位、同时含字母和数字的新密码。完成前不能查看档案或进入工作台；以后使用新密码登录。
4. 连续 5 次验证失败锁定 15 分钟。初始密码状态自首次尝试起有效 7 天，过期需管理员重置。手机号缺失、重复、停用、未审核、演示档案不能自动开通手机号登录。
5. 修改档案手机号后，已有手机号会话失效；请管理员核实并重置以绑定新号码。旧短码和编辑码仍可使用。

## 权限与存储

`xg_counselor_accounts` 和 `xg_counselor_invites` 按正式/preview 前缀隔离，只允许服务端访问，不加入通用 REST 白名单。

账号记录保存手机号绑定摘要、scrypt 密码摘要、失败次数、锁定时间和会话版本。初始改密、资料填写、正常工作台会话使用不同 audience。手机号会话每次请求都核验版本和当前号码；分享会话每次请求都核验撤销、版本和到期时间。

分享秘密为 256 位随机值，数据库只存摘要。链接采用 URL fragment，打开后立即从地址栏移除；填写会话只在当前页内存中保存，最长 30 分钟。刷新后需重新打开原链接。资料响应不返回编辑码、短码或认证摘要。

服务端沿用原有私有照片上传和资料字段校验。仅手机号绑定和登录状态在新集合中更新，不批量覆盖已有档案或重设密码。

## 验证与发布

```sh
npm test --prefix cloudrun/xiaopingu-api
node --test scripts/test-chain/frontend.test.cjs scripts/web-auth-boundary.test.cjs
node scripts/verify-counselor-access-browser.cjs
```

浏览器脚本使用合成内存数据，需 Playwright；可通过 `NODE_PATH` 与 `XPG_CHROMIUM_PATH` 指定本机依赖。

先创建两套仅服务端可读写的集合，再部署支持新接口的 preview 和正式后端，最后上传新增的 `assets/counselor-access.js`、`assets/counselor-access.css` 及三个引用页面 `admin.html`、`index.html`、`counselor.html`。保留现有服务环境变量和私有桶权限。未部署新后端前不要先开放新登录入口。
