# 来访—咨询师—四评—后台完整链路操作

## 从哪里开始

在本项目目录运行 `npm run test:journey`，打开：

**http://127.0.0.1:8796/journey.html**

这是本机可视化入口，接口和记录实际保存在 CloudBase 独立测试区 `xg_preview_7d0a8e2622_`。正式区 `xg_v2_59875df34c_` 不参与测试。首页固定标出“独立联调测试区”；不要在这里填真实姓名、联系方式或真实经历。

第一次准备身份用 `npm run test:journey:setup`。已经准备过无需重复。测试账号明文仅在本机 `.private/test-chain/accounts.md`；页面的角色按钮会通过正常登录 API 取得各自会话，省去手工复制。它不是一个可以越权扮演所有人的业务账号。

如果后台提示登录过期，回到体验入口重新点击相应角色。来访者填写凭证、咨询师编辑码、管理员密码不能混用；评估编号和咨询师 ID 都不是登录密码。

## 路线 A：立即体验咨询师审批

1. 进入体验入口，点击“准备待审批测试申请”。系统通过正式业务接口写入一条明确标记的合成初评并向本轮测试咨询师申请。
2. 点击“进入测试咨询师工作台”。找到对应合成来访者、状态“待审核”，填写可选备注，点击“通过匹配申请”并确认。
3. 页面刷新后出现“进行中”的新版周期。点击进入；它的 match_id 与来访者看到的是同一个周期。
4. 未有来访者评估同意时，咨询师可能暂无可填卡，先按下一节切换来访者签署。

此路线不会自动替咨询师审批；申请必须由你在咨询师角色点击通过。测试账号的入驻资料已在测试区审核通过，确保它能成为申请对象。

## 路线 B：从来访注册和原始初评开始

1. 在体验入口点击“创建新一轮测试身份”，创建一对空白身份，旧测试数据保留。
2. 点击“从首页开始初评”，按原页面完成进入验证、基础资料、准入筛查和初评。页面验证码由你本人完成。
3. 仅填合成资料，例如“合成测试来访者”。正常流程选不触发危机准入红线的测试答案；若故意选红线答案，系统应阻止后续匹配，不应为了演示绕过它。
4. 初评保存时客户端生成或使用独立填写秘密，服务端绑定本人身份。测试入口预置的是本轮测试来访者的独立凭证。
5. 匹配结果定向展示本轮“合成测试咨询师”，点击申请并填写合成联系说明。该定向排序仅在本机测试入口启用，正式匹配算法不受影响。
6. 回到体验入口，切换测试咨询师，按路线 A 第 2 步审批。

每对身份只能有一个相同双方的进行中周期。如要再演示一条全新链路，创建新轮次；如要模拟再次咨询，先由咨询师结案旧周期再申请。

## 双方填写四评

### 来访者

1. 回到体验入口，点击“进入测试来访者四评”，打开同一个进行中周期。
2. 点击“评估知情说明”，阅读并主动确认测试用途的说明。旧签署和评估编号不会代替这一步。
3. “查看本节待填卡片”首先给出基线卡。按页面题目逐项填写并提交；显示“已保存”后返回。
4. 第 1 节填写感受卡。首节状态重测有条件和时间限制，不应强行插入普通状态卡。
5. 咨询节次改为第 2 节后，填写状态卡与感受卡。状态核心七题固定 0–70，选修单独计算。
6. 来访者界面只展示已保存和记录状态，不显示四评分数、预警或咨询师专业卡原始内容；这是预期行为。

### 咨询师

1. 切换“进入测试咨询师工作台”，打开同一周期，选择与来访者相同的节次。
2. 查看待填卡片并填写专业判断卡。第 1 节 p6 不适用，完整六题总分为空是预期；不能补成 0。
3. 第 2 节起按当前冻结题面填写。本次卡片一经开始，后续配置变更不改写它的题目或计分依据。
4. “关注点与选修题”用于人工维护动态关注点和选修开关；“阶段对照”“状态趋势”查看专业端允许的数据。
5. “提醒与复核”展示符合条件的提醒。测试区可以演示系统内复核，真实微信/短信通知和 LLM 始终未开启。

## 在后台看具体数据和结果

1. 从体验入口点击“进入测试运营后台”。
2. 点击运营看板“咨询师总数 · 查看全部”，进入完整咨询师列表。可以筛选待审/已通过/停用等状态，点击“查看”读取完整资料。
3. “匹配申请”能看到合成初评对应的申请及审批状态。
4. “循证咨询”读取新版周期和事件，展示双方关联、提交数量。点击“查看四评记录与结果”，进入该周期。
5. 点击“查看新版填写记录”查看管理员可见的卡片结果和允许的原始题目值；“阶段对照”查看基线、结案和随访，状态趋势与跨量表对照不是同一个数值。
6. 单个测试来访者的运营比例可能显示“样本不足”，因为统计按不同来访者人数执行保护；这不表示没有记录。具体个案仍可以查看。

可复核的合成示例：基线核心七题都填 7，主分应为 **49**；第 2 节状态核心七题都填 6，主分应为 **42**。补充题、资源题和选修题不加进这 70 分主量程。全部相同的答案可能被标记为低质量，标记会保留，这也是质量规则的预期结果。

## 结案与随访

咨询师在原周期选择真实测试节次并确认结案。来访者需确认“结束与随访知情说明”，再填写结束卡与咨询评价。随访按结案后的 1/3 自然月到期开放；不能为了立即看到结果伪造随访时间。测试不发送真实通知。

## 常见问题

- **咨询师有 ID 却 403**：ID 只标识资料，需本人编辑码登录。入驻未审核或已停用也不可操作；不要改用匿名 key。
- **历史记录审批提示重新申请**：没有新版 current_request_id 的旧历史不会自动恢复为进行中咨询。
- **只能看到旧历史，不能填卡**：使用的是历史凭证。请使用本轮独立来访填写凭证。
- **咨询师在库里但匿名列表没有**：后台目录包含所有状态；对来访者开放的匹配列表只含已通过且启用的咨询师。
- **正式默认域名下载文件或提示访问限制**：当前未绑定正式自定义域名；这不影响本机联调入口访问独立测试后端。正式公开页面仍需要已备案域名及 HTTPS。
- **重启电脑后本机入口打不开**：重新运行 `npm run test:journey`。测试记录仍在 CloudBase，不随本机服务退出丢失。

源码和准确的接口字段见 [v2 源码与接入契约](v2-source-and-api.md)。自动化合成链路验收结果在 `outputs/test-chain/api-verification.json`；运行脚本为 `node scripts/test-chain/verify.cjs`，会向本轮合成身份新增测试记录。
